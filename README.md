# مدبّر - إدارة أموالك بذكاء

لوحة تحكم عربية (RTL) متجاوبة لإدارة الأموال، مبنية بـ HTML و CSS فقط.

## الأقسام

- الرصيد والدخل والمصروفات
- الأنشطة الحديثة والمعاملات الأخيرة
- الفواتير الشهرية ونظرة عامة على الميزانية
- رسم بياني للدخل مقابل المصروفات
- ملخص الحساب
- وسائل الدفع (البطاقة بتتقلب عند الوقوف عليها أو الضغط)

## ترتيب الملفات

```
├── index.html
├── CSS/
│   ├── style.css           # التصميم الأساسي
│   └── media-query.css     # التصميم المتجاوب
└── Images/
    └── Icons/
```

## التشغيل

افتح `index.html` في أي متصفح حديث.

## الـ Breakpoints

| عرض الشاشة | التغيير |
|---|---|
| أكبر من 1280px | القائمة الجانبية و3 أعمدة |
| 1280px وأقل | ترتيب جديد للكروت |
| 1023px وأقل | إخفاء القائمة الجانبية |
| 767px وأقل | عمود واحد |
| 480px وأقل | مسافات وخطوط أصغر |

## ملاحظة

مشروع تدريبي للواجهة فقط، وكل البيانات تجريبية.
